## GitHub Actions
1. Merge Any Uplifts
2. Run *Shippable Build & Signing* Task on GitHub
3. Correct Any failures
4. Sign off at end of pipeline
5. Update Release with contributions/ changelog

## Fdroid Actions
1. Fork, then clone [fdroid](https://gitlab.com/fdroid/fdroiddata/) (if already cloned, you may want to pull from original repo to work off of tip)
2. Pin to release and add any notes
3. Push To fork
4. Create Merge Request

## Google Play Store

2. Promote Release to Production
